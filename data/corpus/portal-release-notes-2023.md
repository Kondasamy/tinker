Larkspur Portal release notes, 2023.

February release: approvers can now approve or reject orders from the email notification. Order history exports include the approver's name and the approval time.

April release: the Kestrel K2 handheld scanner is now supported for warehouse receiving. Receivers can scan a pallet label and confirm every line on the packing slip from the scanner screen. The Kestrel K2 scanner integration is owned by the Fulfillment Systems team.

June release: saved carts can be shared with colleagues. A shared cart shows who added each item and when.

August release: the catalog search understands part numbers with or without dashes. Search results show stock levels for the customer's nearest warehouse.

October release: invoices can be downloaded as a single combined PDF for a date range. Purchase-order customers can see the remaining balance on each purchase order.

December release: dark mode for the Portal admin area. Performance improvements make large order lists load roughly twice as fast.

Known issues: some older browsers show the dark mode toggle in the wrong place. A fix is planned for the first release of 2024.
